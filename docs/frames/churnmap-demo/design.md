# churnmap demo visual identity

Purpose: short product demo for a developer CLI that turns git co-change history into an interactive risk map.

Audience: platform engineers, tech leads, staff engineers, and maintainers preparing refactors.

Palette:
- Canvas: #f6f7f2
- Ink: #111318
- Muted ink: #4b5563
- Panel: #ffffff
- Rule: #d8ded6
- Teal accent: #0f766e
- Risk red: #be123c
- Review amber: #b45309
- Code violet: #6d28d9

Typography:
- Display: high-contrast serif
- Interface: system sans
- Code and data: system monospace

Motion:
- Confident, mechanical, and readable.
- Elements lock into place like a diagnostic tool assembling evidence.
- Data should fill, count, connect, and pulse rather than float.

Avoid:
- Stock SaaS gradients.
- Centered feature-card grids.
- Purple-blue dominance.
- Tiny UI labels that disappear in video renders.
