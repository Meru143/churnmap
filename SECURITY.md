# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of churnmap.

## Reporting a Vulnerability

Report vulnerabilities privately by emailing security@example.com. Include:

- Affected version or commit.
- Steps to reproduce.
- Expected and actual impact.
- Any relevant logs or generated report snippets.

Please do not open public issues for security vulnerabilities. Maintainers will acknowledge reports within 7 days and coordinate disclosure after a fix is available.
